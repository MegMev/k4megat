# 备注：

 **从原有的combieGasAndCZT.C出发，将原有的算法移植到新的Gaudi框架中（注：参考KalmanFilter的做法）。原有的算法主要是针对气体以及CZT中的点进行了不同的处理，所以就将主体过程分为了以下三个部分：**

1. **处理气体中的**

   - 1.1初始化变量

   - 1.2 遍历所有命中点

        - 过滤出气体中的点

        - 计算和更新电荷中心

       - 存储气体中的点并应用能量扰动

       - 更新轨迹的最小和最大坐标值

   - 1.3 计算轨迹范围

   - 1.4 计算边界中心

2. **识别主径迹并进行处理**

   - 2.1 识别主径迹ID

       - 统计每个轨迹的命中点数量

       - 找出命中点最多的轨迹ID

   - 2.2 遍历所有命中点

       - 区分主径迹和次生径迹的点

       - 存储主径迹和次生径迹的点并应用能量扰动

       - 计算主径迹点到边界中心的距离

   - 2.3 处理主径迹和次生径迹的点

       - 将处理后的主径迹点添加到输出集合

       - 将处理后的次生径迹点添加到输出集合

3. **处理CZT中的点**

   - 3.1 遍历所有命中点

       - 过滤出CZT中的点

       - 应用能量扰动和坐标栅格化

   - 3.2 存储处理后的CZT点

       - 将处理后的CZT点添加到输出集合
